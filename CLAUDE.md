## Project Overview

Dev Tool Hype ("Hype Barometer") is a full-stack application that tracks trending AI development tools. It aggregates data from GitHub, Hacker News, Reddit, and PyPI, then ranks tools by a "hotness" scoring algorithm to surface emerging trends.

## Commands

### Backend (Python)
```bash
# Install dependencies
pip install -r requirements.txt

# Run the data pipeline (from repo root)
python -m scripts.main
```

Requires `GITHUB_TOKEN` environment variable (or in `.env` file).

### Frontend (Next.js)
```bash
cd frontend
npm install
npm run dev      # Development server at http://localhost:3000
npm run build    # Production build
npm run lint     # ESLint
```

## Architecture

### Data Pipeline (`scripts/`)
The pipeline runs sequentially with parallel fetches for HN/Reddit:

1. **discover_trending_repos** - GitHub API search for repos < 6 months old, sorted by stars
2. **scrape_github_trending** - Scrapes GitHub Trending page for `stars_period` velocity
3. **Seed tools** - Merges repos from `tools.yaml` (always tracked)
4. **fetch_all_hn_metrics / fetch_all_reddit_metrics** - Parallel fetch via ThreadPoolExecutor
5. **enrich_repos** - Batch fetch GitHub stats (stars, forks, commits, created_at)
6. **Deduplication** - Handles renamed repos, merges HN/Reddit mentions
7. **Filter emerging** - Only keeps repos created within last 6 months
8. **check_corporate_bulk** - Flags corporate repos (0.7x score penalty)
9. **fetch_pypi_for_repos** - PyPI download stats
10. **calculate_scores** - Weighted scoring with log-scale normalization

### Scoring Algorithm (`scripts/calculate_scores.py`)
Weights: stars 30%, commits 20%, HN points 15%, stars/week 10%, HN mentions 10%, Reddit points 10%, Reddit count 5%. Repos with < 1000 stars get additional penalty (stars/1000). Uses log-scale normalization.

### Frontend (`frontend/`)
- Next.js 16 + React 19 + Tailwind CSS v4 + shadcn/ui
- Main component: `components/hype-barometer.tsx` - Displays ranked tools with animated flame effects
- Reads data from `public/data.json` (generated by Python pipeline)
- Pages: `/` (main rankings), `/about`

### Data Flow
```
scripts/main.py → data/current.json + data/snapshots/{date}.json
              → frontend/public/data.json → Next.js frontend
```

## Key Files

- `tools.yaml` - Seed list of tools to always track (with categories, GitHub URLs, PyPI names)
- `scripts/config.py` - Paths and configuration
- `data/current.json` - Latest rankings and raw repo data
- `frontend/components/hype-barometer.tsx` - Main visualization component
